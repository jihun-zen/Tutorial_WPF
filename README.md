# 읽기용 PDF 교재

[4주 통합 교재 PDF](WPF_4주_통합교재.pdf)에 개발환경 안내와 16회 수업을 모았습니다. 첫 목차의 수업 제목과 PDF 책갈피로 이동할 수 있습니다.

개별 파일은 원본 lessons 폴더와 같은 구조입니다.

| 준비 | [개발환경 안내](lessons/setup.pdf) |
| 1주차 | [1일](lessons/week01/day01.pdf) · [2일](lessons/week01/day02.pdf) · [3일](lessons/week01/day03.pdf) · [4일](lessons/week01/day04.pdf) |
| 2주차 | [1일](lessons/week02/day01.pdf) · [2일](lessons/week02/day02.pdf) · [3일](lessons/week02/day03.pdf) · [4일](lessons/week02/day04.pdf) |
| 3주차 | [1일](lessons/week03/day01.pdf) · [2일](lessons/week03/day02.pdf) · [3일](lessons/week03/day03.pdf) · [4일](lessons/week03/day04.pdf) |
| 4주차 | [1일](lessons/week04/day01.pdf) · [2일](lessons/week04/day02.pdf) · [3일](lessons/week04/day03.pdf) · [4일](lessons/week04/day04.pdf) |

A4 용지에 맞춰 한글 글꼴을 포함했습니다. 긴 코드 줄은 읽기 편하게 줄바꿈했으므로, 실행할 코드는 원본 Markdown 또는 sample의 소스 파일을 사용하세요. 코드 파일 링크를 사용할 때는 이 저장소도 함께 보관합니다.

원본 Markdown은 그대로 유지했습니다. 원본을 수정한 뒤 PDF를 다시 만들려면 Python과 reportlab이 있는 환경에서 저장소 루트의 `tools/export_lessons_pdf.py`를 실행합니다.
